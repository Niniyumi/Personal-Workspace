## 用户验收：约 10 分钟

### 1. 邮箱认证

1. 使用一个真实邮箱获取注册验证码并完成注册。
2. 登录后退出，再执行忘记密码。
3. 使用邮件验证码设置新密码，确认旧密码不能登录、新密码可以登录。

### 2. 周报和总结

1. 同时上传 2—3 份包含日期和三个常见章节的 DOCX。
2. 检查日期归周、同周合并和三栏分类后保存。
3. 打开保存后的周报并修改一次。
4. 选择包含这些周报的季度，生成总结并保存一次。

### 3. 课程录音

1. 录制 10—20 秒并结束录音。
2. 等待转写完成，先回听原始录音并检查完整文字。
3. 手动点击“生成笔记”，修改笔记并保存。
4. 刷新页面，确认原始录音、转写和笔记均存在。

## 通过标准
