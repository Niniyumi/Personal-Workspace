# 2026-08-23 开发进度

## 当日目标

完成 Personal Agent 的工程设计、认证后端和真实数据库验证，为登录网页开发建立稳定基础。

## 已完成内容

### 项目与架构

- 明确多用户 Personal Agent 的产品边界和分阶段路线。
- 确认后端采用 Java 21、Spring Boot 3.5.16、MyBatis-Plus 3.5.17 和 MySQL 8。
- 确认前端采用 Vue 3、TypeScript、Vite、Vue Router、Pinia 和 Axios。
- 坚持模块化单体与 YAGNI，首个增量没有加入 Redis、RabbitMQ、微服务和模型路由框架。

### 认证后端

- 完成用户注册、用户名或邮箱登录、当前用户查询和退出。
- 完成 15 分钟 Access Token 与 7 天 Refresh Token。
- 密码使用 BCrypt；刷新令牌在数据库中只保存 SHA-256 摘要。
- 刷新令牌使用原子条件更新，防止同一令牌被重复消费。
- 禁用用户无法继续访问受保护接口。
- 统一参数错误、认证失败、权限不足和业务冲突响应。
- 使用 Flyway 创建 `users` 和 `refresh_sessions` 表。

## 重要技术决策

- 本地开发使用被 Git 忽略的 `application-local.yml`；部署时使用环境变量。
- 用户名禁止 `@`，登录输入包含 `@` 时按邮箱查询，否则按用户名查询。
- MySQL 是认证会话事实来源，当前不引入 Redis。
- 前端登录页不使用重量级 UI 组件库和表单库。
