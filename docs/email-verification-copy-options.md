# 验证码邮件文案候选

这些文案参考主流认证产品的邮件结构后重新撰写，不复制具体产品措辞。共同原则是：主题直接说明用途，验证码醒目，明确有效期，并提醒非本人操作可忽略；认证邮件不混入营销内容。

占位符：`{验证码}`、`{有效分钟}`、`{产品名}`。当前程序对应值为 6 位验证码、10 分钟、`Personal Agent`。

## 方案 A：极简版（推荐）

注册主题：`【{产品名}】注册验证码：{验证码}`

```text
你好，

你的注册验证码是：{验证码}

验证码在 {有效分钟} 分钟内有效，请勿转发给他人。
如果不是你本人操作，请忽略此邮件。

{产品名}
```

找回密码主题：`【{产品名}】重置密码验证码：{验证码}`

```text
你好，

你正在重置密码，验证码是：{验证码}

验证码在 {有效分钟} 分钟内有效，请勿转发给他人。
如果不是你本人操作，请忽略此邮件，你的密码不会被更改。

{产品名}
```

## 方案 B：友好版

注册主题：`欢迎使用 {产品名}，请完成邮箱验证`

```text
你好，欢迎使用 {产品名}。

请输入下面的验证码完成注册：

{验证码}

该验证码将在 {有效分钟} 分钟后失效。为了账户安全，请不要告诉其他人。
若你没有发起注册，可以直接忽略这封邮件。

{产品名} 团队
```

找回密码主题：`请使用验证码重置你的 {产品名} 密码`

```text
你好，

我们收到了你的密码重置请求。请在页面中输入验证码：

{验证码}

验证码 {有效分钟} 分钟内有效。若你没有发起此操作，请忽略邮件，无需进行其他操作。

{产品名} 团队
```

## 方案 C：安全提示版

注册主题：`{产品名} 邮箱验证 | 验证码 {验证码}`

```text
本次邮箱验证的验证码为：{验证码}

用途：注册 {产品名} 账户
有效时间：{有效分钟} 分钟

请勿向任何人提供验证码。{产品名} 工作人员不会向你索要验证码。
非本人操作请忽略此邮件。
```

找回密码主题：`{产品名} 安全验证 | 重置密码验证码`

```text
本次安全验证的验证码为：{验证码}

用途：重置 {产品名} 登录密码
有效时间：{有效分钟} 分钟

请勿向任何人提供验证码。若非本人操作，请忽略邮件并不要提交验证码。
```

## 建议

小规模项目直接选方案 A。它信息完整、纯文本显示稳定，也和当前 `SimpleMailMessage` 实现最匹配，不需要增加 HTML 模板引擎。
