# 课程录音转笔记测试用例

## 自动化覆盖

- 登录用户创建课程，标题会去除首尾空格并进入 `RECORDING`。
- 课程、详情和笔记修改始终按当前用户隔离。
- 相同分片重复上传不重复写文件；完成前校验分片编号连续且总时长不超过 90 分钟。
- 完成录音后进入 `PROCESSING`；逐片转写并按顺序拼接，再生成 Markdown 笔记。
- 成功后进入 `READY` 并删除临时音频；Provider 失败进入 `FAILED` 并保留音频供手动重试。
- 前端 multipart 字段、最终分片先上传再完成、麦克风拒绝、受保护路由、列表和详情编辑均有测试。

## 本地冒烟测试

1. 配置 `SPEECH_API_KEY`、`AI_API_KEY` 和 `AI_MODEL`，启动 MySQL、后端和前端。
2. 登录后进入“课程笔记”，输入课程名并允许麦克风权限。
3. 录制 10—20 秒，点击“结束并整理”，确认页面显示“整理中”。
4. 打开课程详情，等待状态变为“已完成”，检查完整转写和五个固定笔记模块。
5. 修改笔记并保存，刷新页面确认内容仍存在。

真实语音接口需要网络和有效密钥，因此只作为手工冒烟测试，不伪装成自动化通过。
