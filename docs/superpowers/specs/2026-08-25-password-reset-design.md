# 邮箱验证码重置密码设计

## 目标

用户在登录页进入“忘记密码”，填写注册邮箱，接收 QQ 邮箱发送的 6 位验证码，再填写验证码和新密码完成重置。

## 后端

- 引入 Spring Mail，通过 `MAIL_USERNAME` 和 `MAIL_AUTH_CODE` 连接 QQ SMTP。
- 新增 `password_reset_codes` 表，保存用户 ID、验证码摘要、过期时间和使用时间。
- `POST /api/auth/password-reset/request`：接收邮箱；邮箱存在时生成验证码并发送邮件。无论邮箱是否存在都返回相同成功响应。
- `POST /api/auth/password-reset/confirm`：接收邮箱、验证码和新密码；验证码正确且未过期时更新 BCrypt 密码并标记验证码已使用。
- 验证码为 6 位数字，有效期 10 分钟；新验证码生成后，旧验证码不再有效。
- 日志只记录发送或重置是否失败，不记录密码、验证码、授权码和完整邮箱。

## 前端

- 登录页增加“忘记密码”链接。
- 新增 `/forgot-password` 页面：第一步发送验证码，第二步填写验证码、新密码和确认密码。
- 成功后返回登录页并显示“密码已重置”。接口错误显示明确提示并记录一次请求日志。

## 测试

- 后端测试验证码生成、正确重置、错误或过期验证码、未知邮箱统一响应。
- 前端测试 API 契约、表单流程和登录页入口。
- 最后各运行一次前后端全量测试与前端构建。

## 不做

暂不引入 Redis、图形验证码、复杂限流、多邮件服务商切换和管理员重置密码。
