# 真实看板与分步课程笔记设计

## 目标

把首页从静态展示页改为真实数据看板，并把课程处理改成“先保留录音和转写，再由用户主动生成笔记”。全站文案以功能为主，删除无效控件、开发阶段文字、重复英文标签和技术栈宣传。

## 范围与约束

- 面向小规模使用，不引入 Redis、队列、统计平台或图表依赖。
- 保留当前 Vue 3、Element Plus、Spring Boot、MyBatis-Plus、MySQL 和本地音频存储。
- 不重写数据库；`courses.transcript`、`courses.note_content` 和 `course_audio_parts` 继续使用。
- 原始录音、完整转写和生成后的笔记长期保留，除非以后单独增加用户主动删除功能。
- 自动化测试不得调用阿里云；真实录音验收才允许使用百炼额度。

## 首页看板

首页删除禁用的搜索框、中央输入框、上传按钮、发送按钮、33%、PHASE 01 和静态最近进度。

新首页包含：

1. 近 6 个月产出趋势：每月周报数与已完成课程笔记数，使用原生 SVG/CSS 柱状图，并显示文字图例和数值。
2. 本月概览：本月周报数、本月完成笔记数、本月录音分钟数。
3. 周报入口：累计已保存周报数、本月新增数、“写周报”和“工作总结”。
4. 课程入口：累计已完成笔记数、累计录音分钟数、“开始录音”和“查看课程”。
5. 最近记录：合并最近的周报和课程，按更新时间倒序展示，点击进入详情。

新增 `GET /api/dashboard`。后端针对当前用户读取周报和课程列表，在内存中完成统计和近 6 个月聚合。当前使用规模小，这比新增统计表和复杂 SQL 更易维护。

## 课程处理流程

课程状态保留现有 `RECORDING`、`PROCESSING`、`READY`、`FAILED`，只增加 `TRANSCRIBED`。

流程如下：

1. 录音期间每 5 分钟上传一个 WebM 分片，立即保存到本地存储并记录 `course_audio_parts`。
2. 结束录音后进入 `PROCESSING`，异步调用 `qwen3-asr-flash` 转写全部分片。
3. 转写成功后立刻把完整文字保存到 `courses.transcript`，状态变为 `TRANSCRIBED`，不调用笔记模型、不删除录音。
4. 课程详情显示原始录音、完整转写和“生成笔记”按钮。
5. 用户点击后调用 `POST /api/courses/{id}/note/generate`，状态暂时进入 `PROCESSING`，异步调用 `qwen-plus`。
6. 生成成功后保存 `note_content` 并进入 `READY`；生成失败时回到 `TRANSCRIBED`，保留录音和转写并允许重试。
7. 转写失败进入 `FAILED`，保留录音并允许重新转写。

新增录音读取接口：

- `GET /api/courses/{id}/parts`：返回当前用户课程的录音分片元数据。
- `GET /api/courses/{id}/parts/{partNumber}/audio`：鉴权后返回单个 WebM 分片。

音频始终按 `userId + courseId` 校验归属，不能仅凭分片编号读取。

## 当前模型调用

- 语音转写：阿里云百炼 OpenAI 兼容接口，默认 `qwen3-asr-flash`。
- 笔记生成：同一兼容接口，默认 `qwen-plus`，temperature 为 0。
- 笔记提示词固定要求课程摘要、核心知识点、重要概念、案例和复习提纲，并禁止编造原文没有的内容。

本次只拆分调用时机和保存边界，不更换模型。

## 页面精简

- 认证页保留品牌、表单和必要反馈，删除 `ISSUE 01`、Java/Spring/Vue 技术栈和重复产品故事。
- 周报页保留“新建周报、历史周报”；详情页以日期为标题，不展示装饰性记录编号。
- 工作总结页保留周期选择、生成、编辑、保存和模型内容提示。
- 课程页突出课程名称、录音控制和历史记录；详情页按“原始录音、完整转写、课程笔记”排列。
- 所有功能页压缩巨幅口号和重复英文眉题；保留必要的返回入口、错误提示和空状态。
- 路由页面改为懒加载，减少首页首次加载体积。

## 错误与状态

- 看板加载失败显示一条简短错误和重试按钮，其他功能入口仍可使用。
- 转写失败不删除录音；笔记失败不删除录音或转写。
- 播放某段录音失败只影响该段，显示可重试提示。
- 页面以明确中文区分“正在转写”“文字已提取”“正在生成笔记”“笔记已完成”。

## 验收标准

- 首页不再出现任何开发阶段或无功能控件，所有数字来自当前账号真实数据。
- 周报和课程统计、近 6 个月趋势、最近记录与数据库内容一致。
- 结束录音后先得到并保存转写，只有点击按钮才调用笔记模型。
- 笔记模型失败后仍能查看录音和转写并重新生成。
- 原始录音成功后不会被后台自动删除，并且只能由所属用户播放。
- 页面在桌面和手机宽度下都无横向滚动，键盘焦点和加载/错误状态清晰。
